# Kinich development preference

The user requires every existing dynamic effect to remain available. Never delete or permanently disable Kinich's animations, ambient effects, click feedback, Ajaw reactions, or immersive parallax as a performance shortcut. Optimize rendering and event lifecycles while preserving their visible behavior and the user's existing motion/intensity settings. Respect `prefers-reduced-motion` as an accessibility override; it is not removal of the effects.

Keep DSH-owned navigation, sessions, composer actions, settings, and keyboard behavior intact. Verify changes in an isolated profile before publishing.
