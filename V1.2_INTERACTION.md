## Feedback contract

| Signal | Feedback |
| --- | --- |
| Text control focus | Thin lime/gold focus treatment on the focused control |
| Host action press | 190 ms tactile pressed state on the activated control |
| Send action | Ajaw `↗`, warm-gold badge, and dashed ring |
| Session running | Ajaw `…`, lime badge, and dotted ring |
| Session complete | Ajaw `✓`, pale-lime badge, and double ring |
| Session error | Ajaw `!`, red badge, and solid warning ring |

The bridge does not replace DSH controls or intercept their normal behavior. State text remains available through an invisible live region instead of a floating composer prompt. Reduced-motion mode removes nonessential motion while retaining visible Ajaw state changes and live-region announcements. Low balance changes Ajaw only through a red tint and 2× animation speed; it no longer locks or suppresses any task state or interaction.

## Pointer burst

Primary mouse clicks create a code-drawn local burst at the exact client coordinate. The peak frame matches the approved concept: a luminous pale-lime diamond, broken pixel-diamond ring, short energy arc, and ten lime/teal/warm-gold square fragments. The footprint stays around 72 px, the animation finishes in roughly 260 ms, at most four concurrent bursts are retained, and the layer never receives pointer events. Touch input and reduced-motion mode do not render the effect.

The burst list lives inside one permanently mounted, pointer-transparent layer. Adding a burst therefore cannot shift or remount the Overlay's interactive siblings during an active pointer sequence; Ajaw click/drag and its balance popover keep stable component identity.
